# Mohammad Kaif — Data Engineering Portfolio

Personal site for Data Engineering work: pipelines, SQL, Python, Spark, and Databricks.

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Replace placeholders

Edit `src/data/profile.ts`:

- `YOUR_EMAIL`
- `YOUR_GITHUB_URL`
- `YOUR_LINKEDIN_URL`

Edit `src/data/projects.ts` for project copy, tech lists, pipeline steps, and `YOUR_PROJECT_URL`.

Edit `src/data/skills.ts` and `src/data/journey.ts` as your skills and learning path change.

Search the repo for `YOUR_` to catch remaining placeholders.

## Introduction video

Add these files (do not commit large binaries if you prefer hosting the video elsewhere):

- `public/intro-video.mp4`
- `public/intro-thumbnail.jpg`

Until they exist, the hero shows a placeholder card. Playback only starts after the play button is clicked.

## Optional project images

In `src/data/projects.ts`, set `imageSrc` (for example `/projects/api-mysql.png`) and put the file in `public/`.
